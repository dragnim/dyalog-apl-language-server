This project derives some of its language data from third party sources. No
third party code is copied into it verbatim; what follows is data that was
generated or transcribed from the sources named, which is still enough to
require the notices below.

### What is derived from it

**`src/keyboard.ts` — generated.** The prefix keyboard tables for all thirteen
locales are generated by `tools/gen-keyboard.mjs` from RIDE's `src/kbds.js`,
pinned at commit `66702ddcfb692352d532e395ba3e7ca030f89200`. The generator
applies the same pairing algorithm RIDE's own `src/km.js` uses, so the output is
a transformation of RIDE's layout data rather than a copy of its code.

**`src/control-words.ts` — cross-checked, not derived.** The colon word list was
audited against Dyalog's documentation (see the provenance note in that file)
and cross-checked against RIDE's `src/syntax_info.js`, whose `startBlock` and
`endBlock` lists agree with it. Nothing was copied.

Not currently used, but relevant to planned work: RIDE's `src/bq.js` carries a
fuller set of glyph name aliases than the hand-written list in `src/glyphs.ts`.
Adopting it is tracked in issue #4. Because RIDE is MIT licensed, that adoption
requires preserving the notice above — it does not require permission.
